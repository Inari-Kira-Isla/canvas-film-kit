# canvas-film-kit

Deterministic, hand-drawn Canvas 2D short film toolkit — `kit` CLI (`new`/`doctor`/`gate`/`export`/
`stills`/`determinism`/`boundary-diff`/`fonts`), gates, renderer, scaffold, and templates.

This package is one half of the `canvas-film-kit` monorepo. For the full picture — what this kit
does, the five profiles, the gate/`approved_by` workflow, cross-platform notes, and how to get
started — see the repo root README:

- https://github.com/canvas-film-kit/canvas-film-kit#readme

## Quick start

```bash
npx create-canvas-film my-film --profile abstract
cd my-film
npm install
npm run dev
```
